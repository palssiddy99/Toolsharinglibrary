ToolShare Community Guidelines & Protocol

Standard safety checklist for borrowing and listing machinery.

🥽 1. Wear Protective Gear

Always inspect goggles, ear protection, and gloves before operating high-RPM power tools or blades.

🔋 2. Return Cleaned & Charged

Wipe down grass and sawdust residue. Lithium-ion batteries must be returned with at least 80% charge.

⏱️ 3. Honor Loan Windows

Borrow only for the active duration of your project so other neighbors have equitable access.

⚠️ 4. Report Any Fault Immediately

If an engine stalls or a cable frays, immediately mark it for return and notify the tool owner.
